# 🍵 Two Leaves & a Bud — Tea Website

A modern and colorful **tea and matcha e-commerce website** built using HTML and CSS. The project features a matcha hero section, tea products, customer reviews, brand story, tea discovery, cafe partnerships, lattes, and journal sections.

## ✨ Features

- Modern tea/matcha website design
- Product cards and best sellers
- Customer reviews section
- Brand origins and story
- Tea discovery section
- Cafe & wholesale partners
- Latte product section
- Journal/blog section
- Responsive design
- Custom fonts and hover effects
- Remix Icons

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
- Remix Icons
- Custom Fonts
