# 🎨 Designer Portfolio Dashboard

A modern **designer portfolio dashboard** built using HTML and CSS. The project uses a dark bento-grid layout to showcase a designer's profile, work, social links, tech stack, resources, learning journey, and contact information.

## ✨ Features

- Modern dark bento-grid design
- Designer profile section
- Social media links
- Technology stack section
- Portfolio image cards
- Resources section
- Learning section
- Contact section
- Responsive layout
- CSS hover effects

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Remix Icons
- Google Fonts
