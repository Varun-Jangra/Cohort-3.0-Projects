# 🚀 SaaS Marketing Blog UI

A modern dark-themed blog website built using **HTML and CSS**. The project includes a navigation bar, category buttons, and responsive-style blog cards with images, tags, titles, and dates.

## ✨ Features

- Dark-themed modern UI
- Navigation bar
- Blog category buttons
- Blog cards with images
- Clean and simple design
- CSS hover transitions

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
