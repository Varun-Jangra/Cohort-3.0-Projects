# 🧥 Puffer Jacket Product Page

A modern and responsive **Puffer Jacket product page** built using HTML and CSS. The design includes product information, pricing, size selection, color options, wishlist, add-to-bag button, and product features.

## ✨ Features

- Modern responsive product UI
- Product image and details
- Size selection
- Multiple color options
- Add to wishlist option
- Add to bag button
- Product feature section
- Custom fonts and icons
- CSS hover effects

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
