# 🎨 Branding Agency Website

A modern **creative branding agency website** built using HTML and CSS. The project includes a hero section, services, selected work, team members, testimonials, contact section, and branding insights.

## ✨ Features

- Modern agency-style UI
- Hero and navigation section
- Services and branding sections
- Selected work/projects
- Team members section
- Client testimonials
- Contact section
- Branding insights/blog cards
- Responsive design
- Hover effects and animations
- Infinite scrolling client logos

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Remix Icons
- Responsive Design
