# 🎭 Squid Game Landing Page

A modern **Squid Game-inspired landing page** built using HTML and CSS. The design features a cinematic hero section, character artwork, navigation, social icons, action buttons, and scene preview cards.

## ✨ Features

- Cinematic dark-themed UI
- Squid Game-inspired design
- Hero section with character artwork
- Play Now and Watch Trailer buttons
- Scene preview cards
- Social media icons
- Scroll indicator
- Responsive layout
- Hover effects and animations

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Remix Icons
- Google Fonts
